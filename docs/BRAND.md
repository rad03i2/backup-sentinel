# Backup Sentinel Brand System

Backup Sentinel uses a **Sentinel Vault / Data Integrity** identity: quiet infrastructure design built around trust, verification, and controlled recovery.

The project should feel like a dependable backup appliance or systems utility rather than a generic cyber-security dashboard. The visual language is deliberately different from OCR Desk: darker, denser, and centered on storage layers, checksums, and guarded recovery.

## Identity concept

The visual story is:

**snapshot layers → integrity signal → guarded restore**

The core mark combines three ideas:

- a shield for guarded recovery;
- stacked blocks for versioned snapshots;
- a check signal for verified data.

The logo avoids spelling the project name so it remains recognizable as a small repository card, CLI icon, or future application mark.

## Palette

| Role | Name | Hex |
|---|---|---|
| Main background | Obsidian | `#09110E` |
| Deep surface | Vault Green | `#10271F` |
| Primary signal | Verify Green | `#59E39A` |
| Secondary green | Sentinel Green | `#2DBF7C` |
| Alert accent | Archive Amber | `#F4B740` |
| Primary text | Frost | `#F4F7F5` |
| Secondary text | Muted Sage | `#A9BDB4` |

## Why these colors

- **Obsidian** gives the project a stable infrastructure-tool character without using pure black.
- **Verify Green** represents successful integrity checks and safe completion.
- **Archive Amber** is reserved for caution, restore boundaries, and points that deserve attention.
- **Muted Sage** keeps supporting text readable without competing with verification signals.

## Typography and composition

Repository artwork uses system-safe sans-serif fonts so SVG assets render consistently on GitHub.

- Product name: heavy geometric sans-serif.
- Labels and metadata: compact uppercase sans-serif.
- Commands and paths: monospace in Markdown.
- Arabic developer credit: isolated on its own line to preserve direction and legibility.
- Layout: wide negative space on the left, a guarded snapshot emblem on the right.

## Usage rules

1. Keep the logo square and preserve its internal padding.
2. Keep the hero cover composition intact.
3. Do not add unrelated badges or text on top of the SVG files.
4. Use Verify Green for successful states and Archive Amber sparingly for caution.
5. Do not turn the identity into a neon cyber style; it should remain calm and operational.
6. Do not imply encryption, cloud backup, scheduling, compression, or deduplication as current capabilities.
7. Keep roadmap ideas clearly separated from implemented behavior.

## Distinctive character

Backup Sentinel is positioned visually as a **verification-first local backup utility**. The identity is based on layered storage, integrity signals, and restore protection—not scanning, AI motifs, document paper textures, or generic lock imagery.

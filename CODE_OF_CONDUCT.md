# Code of Conduct

## Our standard

Contributors and maintainers are expected to keep project discussions professional, specific, and respectful.

Good participation includes:

- discussing code and behavior rather than attacking people;
- giving actionable technical feedback;
- respecting different levels of experience;
- protecting private data shared during debugging;
- avoiding harassment, discrimination, threats, or deliberate disruption.

## Project-specific expectation

Backup Sentinel deals with files that may be sensitive. Never ask contributors to publish real private backup contents, credentials, personal documents, or identifying paths when a sanitized reproduction is sufficient.

## Enforcement

Maintainers may edit, remove, or reject content that violates these expectations and may restrict participation when necessary to keep the project safe and constructive.

For sensitive conduct or security concerns, use an appropriate private GitHub reporting channel rather than a public issue.
